# vyxos

Modular and clean NixOS configuration managed with Flakes and Home Manager.

---

## Repository Structure

```text
.
├── flake.nix              # Flake entry point, inputs, and system outputs
├── hosts/
│   └── nyxstation/        # Host-specific configurations
│       ├── default.nix                 # Host entry point and module imports
│       ├── filesystem.nix              # Btrfs mount options
│       ├── hardware-configuration.nix  # Autogenerated hardware config
│       └── nvidia.nix                  # NVIDIA drivers and PRIME configuration
├── modules/               # System-level modular configurations
│   ├── core/              # Bootloader, CachyOS kernel, locale, nix settings, users
│   ├── desktop/           # Desktop environment (Plasma) and fonts
│   ├── hardware/          # Audio (PipeWire), networking, performance tweaks
│   ├── services/          # Tailscale, containers, and background services
│   ├── gaming.nix         # Steam, GameMode, and gaming optimizations
│   └── packages.nix       # System-wide packages
└── home/                  # User configuration via Home Manager
    ├── cli.nix            # CLI utilities and modern unix tools
    ├── editors.nix        # Editor configurations
    ├── git.nix            # Git credentials and configuration
    └── shell.nix          # Shell setup, aliases, and environment
```

---

## Features

- **Flakes & Home Manager**: Declarative system and user environment.
- **Kernel & Performance**: Chaotic-Nyx and nix-cachyos-kernel for low-latency performance.
- **Btrfs Layout**: Subvolume layout (`/`, `/home`, `/nix`) with zstd compression.
- **Desktop**: KDE Plasma on Wayland with NVIDIA PRIME offload support.

---

## Usage

### Clean Install / Hardware Setup

When deploying to a new machine or after a clean installation, update the hardware configuration with the one generated for your machine:

```bash
nixos-generate-config --show-hardware-config > hosts/nyxstation/hardware-configuration.nix
```

### Rebuild and Switch

```bash
sudo nixos-rebuild switch --flake .#nyxstation
```
